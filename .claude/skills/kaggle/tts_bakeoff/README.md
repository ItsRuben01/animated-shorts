# Comparativa TTS open source (Kaggle, gratis)

- `tts_bakeoff_kaggle.ipynb`: el notebook (Kaggle → *Create → Import notebook*).
- `dataset/`: `shots.json` (6 planos de ep12_es, con parámetros de emoción por motor) y `elevenlabs/` (las mismas tomas, recortadas de `public/ep12_es/voice.wav`).

Antes de subir `dataset/` a Kaggle como *Dataset*, añádele **`nebu_ref.wav`**: 8–15 s de tu voz, limpia, sin música (y si quieres, `nebu_ref.txt` con la transcripción exacta).
Accelerator **GPU T4 x2**, Internet **On**, *Run All*.
