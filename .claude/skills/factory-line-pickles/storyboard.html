Hechos y números asumidos

  • Secuencia genérica de una línea industrial: pepino fresco → lavado → salmuera → corte → frasco con salmuera y tapa → etiquetado. Orden confirmado con descripciones de líneas comerciales de pepinillos.
  • El tiempo de curado/fermentación real (días o semanas, según producto) se comprime aquí en un gesto de luz; no se muestra como un paso instantáneo literal.
  • No aparece ninguna cifra de concentración de sal, temperatura ni duración: se evitan números no verificados para este montaje.
  • Se muestra un frasco con tapa; en muchas líneas industriales le sigue pasteurización y enfriamiento antes de etiquetar. Ese paso queda implícito, no afirmado con una temperatura.
  • El color oliva de las rodajas es una simplificación visual del cambio producido por la salmuera, no una medición.
  • Duración total asumida: 11 s. Cada panel usa el instante indicado, no el primer fotograma del beat.
